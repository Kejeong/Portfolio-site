## 1. 제품 개요

**모아**(Moa)는 "**하루를 모아**"라는 슬로건을 가진 감정 기록 앱이다.

모아는 사용자가 하루의 감정과 기록을 가볍게 남기고, 가까운 친구들과 감정과 일상을 공유할 수 있도록 돕는다.

서비스는 두 가지 테마를 제공한다.

- **개인 테마**: 나만 볼 수 있는 비공개 감정 기록 공간
- **친구 테마**: 친구 그룹 안에서 감정, 글, 질문, 댓글을 공유하는 공간

## 2. MVP 목표

모아 MVP의 목표는 사용자가 자신의 하루와 감정을 간단히 기록하고, 친한 친구들과 감정을 공유하며 서로의 하루에 공감할 수 있는 핵심 경험을 제공하는 것이다.

MVP에서는 개인 기록, 친구 그룹, 감정 공유, 그룹 피드, 질문하기, 댓글, 감정 통계를 포함한다.

## 3. 핵심 사용자

모아의 핵심 사용자는 **10~30대** 중 다음 니즈를 가진 사용자다.

- 긴 일기를 쓰기는 부담스럽지만 하루와 감정을 간단히 기록하고 싶은 사용자
- 친한 친구들과 감정을 가볍게 공유하고 싶은 사용자
- 친구의 기록에 공감하거나 댓글로 반응하고 싶은 사용자
- 자신의 감정 흐름을 캘린더와 그래프로 돌아보고 싶은 사용자

## 4. 핵심 사용자 플로우

1. 사용자는 카카오 계정으로 로그인한다.
2. 최초 로그인 후 개인 테마와 친구 테마 중 하나를 선택한다.
3. 이후 앱 실행 시 마지막으로 사용한 테마 홈으로 진입한다.
4. 사용자는 앱 내부에서 개인 테마와 친구 테마를 자유롭게 전환할 수 있다.
5. 개인 테마에서는 비공개 감정 기록을 작성하고 통계를 확인한다.
6. 친구 테마에서는 그룹을 선택하고 글, 감정, 질문을 공유한다.
7. 사용자는 친구 테마 피드에서 그룹 멤버의 글에 공감 반응 또는 댓글을 남길 수 있다.

## 5. MVP 기능 범위

MVP 포함 기능은 다음과 같다.

- 카카오 로그인
- 테마 선택 및 전환
- 개인 테마 피드
- 친구 테마 피드
- 그룹 생성
- 초대 코드 기반 그룹 참여
- 감정 선택
- 글 작성
- 사진 업로드
- 태그 입력 및 기존 태그 추천
- 감정 공유
- 공감 반응
- 댓글 작성, 수정, 삭제
- 질문하기
- 질문 답변
- 월별 감정 캘린더
- 주간 감정 흐름 그래프

푸시 알림과 앱 내 알림함은 MVP에서 제공하지 않는다.

## 6. 로그인

MVP에서는 **카카오 로그인만 제공**한다.

사용자는 카카오 계정으로 가입 및 로그인할 수 있다. 사용자 이름과 프로필 이미지는 카카오 로그인에서 제공되는 닉네임과 프로필 이미지를 기본으로 사용한다.

모아 내 별도 닉네임 변경, 프로필 이미지 변경 기능은 MVP에 포함하지 않는다.

## 7. 테마 선택

최초 로그인 직후 사용자는 `개인 테마`와 `친구 테마` 중 하나를 선택한다.

이후 앱 실행 시에는 마지막으로 사용한 테마 홈으로 진입한다. 사용자는 앱 내부에서 개인 테마와 친구 테마를 자유롭게 전환할 수 있다.

개인 테마와 친구 테마는 피드 UI에서 명확히 구분되어야 한다.

- 개인 테마 피드에는 `나만의 기록` 성격이 드러나는 상단 문구를 표시한다.
- 친구 테마 피드에는 현재 선택한 그룹명을 상단에 표시한다.
- 두 테마는 색감, 아이콘, 배경 톤 등 시각적 스타일에서도 차이를 둔다.

## 8. 개인 테마

개인 테마는 사용자가 본인만 볼 수 있는 하루 기록을 남기는 공간이다.

개인 테마에서 작성한 글은 모두 비공개이며, 친구 그룹 피드나 공유 영역에 노출되지 않는다.

개인 테마 주요 기능은 다음과 같다.

- 비공개 글 작성
- 날짜순 개인 피드
- 감정 선택
- 사진 1장 업로드
- 태그 입력
- 기존 태그 추천
- 글 수정 및 삭제
- 대표 감정 선택
- 월별 감정 캘린더
- 주간 감정 흐름 그래프

개인 테마 피드는 본인이 작성한 비공개 글을 날짜순 목록으로 보여준다. 각 글에는 감정, 작성 내용, 사진, 태그가 표시된다.

개인 테마 글은 본인만 보는 기록이므로 MVP에서는 댓글 기능을 제공하지 않는다.

## 9. 친구 테마

친구 테마는 사용자가 가까운 친구 그룹 안에서 감정과 글을 공유하는 공간이다.

사용자는 여러 개의 그룹을 만들거나 참여할 수 있다. 친구 테마 진입 시 참여 중인 그룹 중 하나를 선택해 해당 그룹의 피드를 확인한다.

친구 테마 주요 기능은 다음과 같다.

- 그룹 선택
- 그룹 생성
- 초대 코드로 그룹 참여
- 그룹 공유 글 작성
- 감정 공유
- 그룹 피드 확인
- 공감 반응
- 댓글 작성
- 질문하기
- 질문 답변 작성

친구 테마에서 작성한 그룹 공유 글은 선택한 그룹의 모든 멤버에게 보인다.

## 10. 그룹 생성 및 초대

사용자는 친구 테마의 `그룹` 탭에서 새 그룹을 만들 수 있다.

그룹 조건은 다음과 같다.

- 그룹당 최대 인원은 5명이다.
- 사용자는 여러 그룹을 만들거나 참여할 수 있다.
- 그룹마다 고유 초대 코드가 발급된다.
- 초대 코드를 입력하면 그룹에 바로 참여할 수 있다.
- 그룹 정원이 5명을 초과하면 참여할 수 없다.
- 그룹장 개념은 없다.
- 모든 그룹 멤버는 동일한 권한을 가진다.
- 모든 멤버는 초대 코드를 확인하고 공유할 수 있다.

그룹 탭에서는 다음 기능을 제공한다.

- 내 그룹 목록 보기
- 그룹 생성
- 초대 코드 입력
- 초대 코드 공유
- 그룹 나가기

MVP에서는 그룹 삭제 기능을 제공하지 않는다.

사용자가 그룹에서 나가도 이전에 작성한 글, 감정 공유, 질문 답변, 댓글은 그룹 피드에 남는다. 작성자 표시도 기존 사용자명으로 유지된다. 단, 그룹에서 나간 사용자는 더 이상 해당 그룹의 피드와 질문에 접근할 수 없다.

## 11. 글 작성

글 작성 시 `감정`은 필수 입력값이다.

선택 입력값은 다음과 같다.

- 글 내용
- 사진
- 태그

사용자는 감정만 선택해도 기록 또는 공유를 완료할 수 있다.

사진은 최대 1장까지 업로드할 수 있다.

태그는 사용자가 직접 텍스트로 입력할 수 있다.

개인 테마의 글 작성 화면에서는 사용자가 이전 개인 기록에 사용한 태그를 추천 목록으로 제공하여 다시 선택할 수 있다. 추천 태그는 삭제되지 않은 개인 기록만 집계하며, 사용 횟수 내림차순으로 최대 8개를 보여준다. 사용 횟수가 같으면 태그명을 오름차순으로 정렬한다. 친구 테마에서 사용한 태그는 개인 테마 추천에 포함하지 않는다.

개인 테마에서 작성한 글은 비공개 글로 저장된다.

친구 테마에서는 별도 업로드 유형을 선택하지 않는다.

- 감정만 선택하고 업로드하면 `감정 공유`로 처리한다.
- 글 내용을 함께 입력하면 `그룹 공유 글`로 처리한다.

작성한 콘텐츠는 작성자 본인만 수정하거나 삭제할 수 있다. 수정 시 감정, 글 내용, 사진, 태그를 모두 변경할 수 있다.

삭제 시에는 삭제 확인 팝업을 표시한다. 사용자가 확인하면 해당 글은 즉시 삭제되며 피드와 통계에서 더 이상 노출되지 않는다.

## 12. 감정 선택

사용자는 글 작성 시 정해진 감정 목록에서 이모지 형태의 감정을 선택한다.

MVP 기본 감정은 다음 6개다.

- 기쁨
- 슬픔
- 화남
- 불안
- 평온
- 피곤

선택된 감정은 개인 기록, 친구 피드, 감정 캘린더, 주간 감정 흐름 그래프에 활용된다.

## 13. 피드

개인 테마 피드는 본인이 작성한 비공개 글을 날짜순 목록으로 보여준다.

친구 테마 피드는 섹션을 나누어 제공한다.

- `공유 피드`: 감정 공유와 일반 그룹 공유 글을 함께 표시
- `질문 답변`: 질문과 답변을 별도 섹션으로 표시

친구 테마 피드의 각 콘텐츠에는 작성자, 감정, 작성 내용, 사진, 태그, 공감 반응 수, 댓글 수를 표시한다.

친구 테마 피드 화면 상단에는 `질문하기` 버튼을 제공한다.

질문하기 조건은 다음과 같다.

- 사용자는 그룹 내 멤버 한 명 이상을 선택해 질문을 보낼 수 있다.
- 하나의 질문은 여러 명에게 전달될 수 있다.
- 질문이 등록되면 즉시 그룹 전체 피드의 `질문 답변` 섹션에 공개된다.
- 질문 대상자는 각자 1개의 답변을 작성할 수 있다.
- 답변은 선택 사항이다.
- 질문 작성자는 본인이 작성한 질문에 답변할 수 없다.
- 답변이 등록되면 같은 질문 아래에 함께 표시된다.
- 질문과 답변은 작성자 본인만 수정/삭제할 수 있다.

공감 반응 조건은 다음과 같다.

- 그룹 멤버는 공유 글 또는 감정 공유 글에 이모지 반응을 남길 수 있다.
- 예시 반응은 `좋아요`, `응원`, `안아주기`다.
- 한 사용자는 하나의 글에 여러 종류의 공감 반응을 남길 수 있다.
- 같은 반응을 다시 누르면 해당 반응만 취소된다.
- 다른 반응을 누르면 기존 반응을 유지하고 새 반응이 추가된다.

## 14. 댓글

댓글은 친구 테마에서 그룹 멤버 간 대화를 이어가기 위한 기능이다.

MVP에서 댓글을 작성할 수 있는 대상은 다음과 같다.

- 그룹 공유 글
- 감정 공유 글
- 질문 답변 글

개인 테마의 비공개 글에는 댓글을 작성할 수 없다.

댓글 작성 조건은 다음과 같다.

- 댓글은 텍스트만 작성할 수 있다.
- 댓글 내용은 필수 입력값이다.
- 빈 댓글은 등록할 수 없다.
- 댓글에는 사진, 감정, 태그를 첨부하지 않는다.
- 대댓글은 MVP에서 제공하지 않는다.
- 댓글은 1단계 구조만 제공한다.

댓글 표시 조건은 다음과 같다.

- 댓글은 해당 글의 상세 화면 또는 피드 내 댓글 영역에서 확인할 수 있다.
- 댓글에는 작성자 닉네임, 프로필 이미지, 내용, 작성 시간을 표시한다.
- 피드 카드에는 댓글 수를 표시한다.
- 댓글은 작성 시간순으로 표시한다.

댓글 권한 조건은 다음과 같다.

- 같은 그룹에 속한 멤버만 댓글을 작성할 수 있다.
- 댓글 작성자 본인만 댓글을 수정하거나 삭제할 수 있다.
- 그룹에서 나간 사용자는 더 이상 댓글을 작성하거나 조회할 수 없다.
- 그룹에서 나간 사용자가 이전에 작성한 댓글은 삭제되지 않고 남는다.

댓글 삭제 조건은 다음과 같다.

- 사용자가 댓글 삭제를 선택하면 삭제 확인 팝업을 표시한다.
- 사용자가 확인하면 댓글은 즉시 삭제된다.
- 삭제된 댓글은 피드와 댓글 목록에 노출되지 않는다.

댓글 수정 조건은 다음과 같다.

- 댓글 작성자 본인만 댓글을 수정할 수 있다.
- 댓글 수정 시 댓글 내용만 수정할 수 있다.
- 수정된 댓글은 수정 시점을 기준으로 `updated_at`이 갱신된다.

MVP에서는 댓글 등록, 수정, 삭제에 대한 푸시 알림과 앱 내 알림함을 제공하지 않는다.

## 15. 통계

개인 테마의 통계 화면에서는 사용자의 감정 기록을 기반으로 월별, 주간 단위의 감정 흐름을 보여준다.

제공 기능은 다음과 같다.

- 월별 감정 캘린더
- 이번 주 감정 흐름 그래프

월별 감정 캘린더는 사용자가 직접 선택한 날짜별 대표 감정을 표시한다.

하루에 여러 개의 감정 기록이 있을 경우, 사용자는 개인 테마 피드의 날짜별 기록에서 해당 날짜의 `대표 감정`을 직접 선택할 수 있다.

사용자가 대표 감정을 선택하지 않은 날짜는 캘린더에서 대표 감정 미선택 상태로 남는다.

이번 주 감정 흐름 그래프는 DB에 저장된 날짜별 `대표 감정`을 기준으로 감정 점수를 막대 그래프로 표시한다.

| 감정 | 점수 |
| --- | --- |
| 기쁨 | 5 |
| 평온 | 4 |
| 피곤 | 2.5 |
| 불안 | 2 |
| 슬픔, 화남 | 1 |

대표 감정이 지정된 날짜는 해당 감정의 점수에 맞는 막대와 이모지를 표시한다. 막대는 0점에서 시작한다.

대표 감정이 지정되지 않은 날짜는 막대·이모지를 표시하지 않고 `미지정` 상태로 표시한다.

하단 감정 점수 범례는 모든 감정을 이모지와 점수로 표시한다. 이번 주에 대표 감정으로 지정되어 막대 그래프에 표시된 감정의 범례만 주황색 배경으로 강조한다.

## 16. 화면 구성

개인 테마 하단 탭은 다음과 같다.

- 피드
- 작성
- 통계

친구 테마 하단 탭은 다음과 같다.

- 피드
- 작성
- 그룹

친구 테마의 `질문하기` 기능은 별도 하단 탭으로 두지 않고, 친구 테마 피드 화면 상단 버튼으로 제공한다.

댓글 기능은 별도 하단 탭으로 두지 않는다. 댓글은 친구 테마 피드의 각 콘텐츠 또는 콘텐츠 상세 화면에서 진입한다.
